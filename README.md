# genai-from-zero

A deploy-ready Next.js 16 learning platform that takes beginners to job-ready AI Engineer in 2026.

## Stack
- Next.js 16.1.6 + React 19.2
- Vercel AI SDK v6
- CopilotKit v2
- Tailwind CSS + shadcn-style components

## Quick start
```bash
npm install
npm run dev
```

## Features
- 21-lesson structured curriculum
- Dynamic lesson routes with progress tracking
- AI mentor chat + interview simulator
- Code playground and portfolio builder
- Light/dark mode
